### MSX Sound Suite Extension

MSX Sound Suite Extensionは、Y8960カートリッジ向けの拡張BASIC、BIOSを総称したものです。以下のソフトウェアを含みます。

## MSX-MUSIC Basic Extension
従来のMSX-MUSIC拡張BIOSとの完全互換性を持ち、MMLが強化されています。従来互換のFMBIOSを搭載しているため、既存のアプリケーションにも対応します。

## MSX-AUDIO Basic Extension Lite

上記のMSX-MUSIC Basic ExtensionをMSX-AUDIO向けに改修したもので、従来のMSX-AUDIO拡張BASICとほぼ互換性があります。ADPCM再生はMMLのみのサポートとなっています。拡張BIOS、MBIOSは搭載していません。

## SFG Basic Extension

上記のMSX-MUSIC Basic ExtensionをSFG-01/05向けに移植したものです。
MSX-MUSIC互換MMLでOPM/OPPを演奏することができます。

## Y8960 Basic Extension
Y8960にネイティブ対応した拡張BASICです。従来のPLAY文のような逐次演奏方式ではなく、MMLコンパイラ方式を取っています。MMLコンパイラが生成したシーケンスデータを最大4つまで同時に保持・演奏することができます。（開発中）

## Y8960 Sequencer BIOS
上記のY8960 Basic Extensionが作成したシーケンスデータを、DOSアプリケーションやROMカートリッジから使用するためのBIOSです。（開発中）
