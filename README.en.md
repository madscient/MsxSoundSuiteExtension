# MSX Sound Suite Extension

[日本語](README.md) | English

MSX Sound Suite Extension (MSSX) is a collection of BASIC extensions and a BIOS for the [Y8960 cartridge](https://github.com/hra1129/Y8960_Cartridge), together with standalone ROMs for other sound chips built from the same code base.

## Download

Get the ROM images from [Releases](../../releases).
**They are licensed for personal use only.** Redistribution requires separate permission from MSX Licensing Corporation ([`NOTICE.md`](NOTICE.md), in Japanese).

| File | Size | Purpose |
|---|--:|---|
| `y8960bas.rom` | 128KB | For the Y8960 cartridge. Contains all five BASIC extensions |
| `standalone/mmbe.rom` | 16KB | Standalone MSX-MUSIC. Replaces the built-in MSX-MUSIC of a computer, or runs as a ROM cartridge |
| `standalone/mabel.rom` | 16KB | Standalone cartridge for MSX-AUDIO (Y8950) |
| `standalone/sfg.rom` | 16KB | Standalone cartridge used together with an SFG-01/05 |
| `standalone/midi.rom` | 16KB | Standalone cartridge that drives a MIDI interface |
| `standalone/makoto.rom` | 16KB | Standalone cartridge for Makoto (YM2608) and Misato (YMF288) |

`y8960bas.rom` shares page 1 (`4000H`-`7FFFH`) among the five BASIC extensions.
At power-on, MSX-MUSIC BASIC Extension V2 is active. `CALL MINIT` / `CALL MUSIC` / `CALL AUDIO` / `CALL OPM` / `CALL MIDI` switch between them.

`standalone/makoto.rom` is for the Makoto and Misato cartridges and is not included in `y8960bas.rom`.

### About the source code

The "Source code (zip)" and "Source code (tar.gz)" files on each release page are added automatically by GitHub to every release. They contain only the documentation and build scripts of this repository. **They do not contain the source code of the BASIC extensions.**

The MSX-MUSIC / MSX-AUDIO / SFG / OPM / MIDI Play / Makoto BASIC Extensions are forks of works copyrighted by Nippon Gakki Co., Ltd. (YAMAHA) and ASCII Corporation, and only distribution of the binaries is permitted. The source lives in private repositories. This repository only holds references to them (`vendor/`), which appear as empty directories in the archives.

## Contents

### MSX-MUSIC BASIC Extension V2

Fully compatible with the original MSX-MUSIC extended BIOS, with an enhanced MML. It includes an FMBIOS compatible with the original, so existing applications work with it.

### MSX-AUDIO BASIC Extension Lite

MSX-MUSIC BASIC Extension V2 adapted for MSX-AUDIO. It is largely compatible with the original MSX-AUDIO BASIC extension. ADPCM playback is supported only through MML. It does not include the extended BIOS or MBIOS.

### SFG BASIC Extension

A port of MSX-MUSIC BASIC Extension V2 to the SFG-01/05. It plays the OPM/OPP with MSX-MUSIC compatible MML. Not included in the Y8960 cartridge image.

### OPM BASIC Extension

SFG BASIC Extension adapted for the OPM built into the Y8960 cartridge. Its statements and MML are the same as SFG BASIC Extension, and it is initialized with `CALL OPM`. No SFG-01/05 is needed. It has no preset voices; create voices as user voices with `CALL VOICE COPY`. Included only in the Y8960 cartridge image.

### MIDI Play BASIC Extension

A BASIC extension that drives a MIDI interface to play MIDI sound modules. It uses MML compatible with MSX-MUSIC BASIC Extension V2, plus some extended commands compatible with MSX-MIDI, and plays MIDI channels 1 to 16 simultaneously.
The following interfaces are detected automatically:
- MSX-MIDI (built into the FS-A1GT)
- MSX-MIDI (μPACK)
- YAMAHA SFG-01 (FM Sound Synthesizer Unit)
- YAMAHA SFG-05 (FM Sound Synthesizer Unit II)
- Philips NMS1205

### Makoto BASIC Extension

A port of MSX-AUDIO BASIC Extension Lite to Makoto, a sound cartridge with a YM2608 (OPNA). It keeps the statements and MML unchanged and plays 6 FM voices, 6 rhythm sounds and 1 ADPCM voice from the `PLAY` statement. It also works on Misato, a sound cartridge with a YMF288 (without ADPCM). Not included in the Y8960 cartridge image.

### Y8960 BASIC Extension

A BASIC extension with native support for the Y8960. Instead of sequential playback like the conventional `PLAY` statement, it uses an MML compiler. It can hold and play up to four sequences generated by the MML compiler at the same time. (In development)

### Y8960 Sequencer BIOS

A BIOS for using the sequence data created by Y8960 BASIC Extension from DOS applications and ROM cartridges. (In development)
